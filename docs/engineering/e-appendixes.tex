\section{Where RetrOS/LT Comes From}\ixs{credits}

RetrOS/LT is a product of The Lyon Mountain Company, Republic Lyon
Mountain Corporation. It is derived from the source code of MS-DOS 2,
which was written by Microsoft Corporation and which Microsoft released to
the public in 2018 under the MIT License. The kernel, \file{COMMAND.COM},
SYSINIT, and the commands \typed{CHKDSK}, \typed{DEBUG}, \typed{EDLIN},
\typed{EXE2BIN}, \typed{FC}, \typed{FIND}, \typed{MORE}, \typed{PRINT},
\typed{RECOVER}, \typed{SORT}, \typed{SYS} and most of \typed{FORMAT} are
that code; \typed{LINK} is Microsoft's program from the same release, and
the assembler and linker that build RetrOS/LT are Microsoft's, from the
MS-DOS 4.0 release. A few routines of \file{RETBIO.COM} follow the IBM PC
BIOS of the MS-DOS 4.0 source, and are marked where they are used.

BASIC is built from the source code of GW-BASIC, which Microsoft released
in 2020 under the MIT License; its part for the IBM Personal Computer,
\file{BASIC.COM} and the sample programs are RetrOS/LT's.

RetrOS/LT is not MS-DOS and is not PC DOS, and neither Microsoft nor IBM
has any part in it.
